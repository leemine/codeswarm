# Gateway 登录与用户独立实例

## 范围与来源

本次收敛已有demo补丁。PR #34（5a8fc97f）将共享组织治理接入Gateway消息、响应和Web UI。
整包回退会同时移除仍需保留的登录、撤销与原共享部署能力。因此本次只在实例部署中
退出共享目录治理，恢复原AgentOS用户路由、文件代理及Runtime执行；未增加第二套执行链。

## 配置

Gateway及Web前端设置 `JIUWENSWARM_GATEWAY_AUTH_FILE` 指向私有认证配置。
文件格式及登录／退出API沿用原组织认证实现，包含authority、签名密钥和带到期／撤销状态的凭据摘要。
文件与密钥只属于入口服务，不能挂载到用户实例；本特性不是IAM账户管理服务。

它与原 `JIUWENSWARM_ORGANIZATION_AUTH_FILE` 互斥。只设置后者的共享组织部署维持原行为；
两者均未设置时保留原未启用该认证的部署路径。不要同时设置两者。

## 保留与退出

- 登录、握手、已认证actor_id以及队列等待后的凭据撤销检查继续执行。
- 实例模式不要求Gateway在本地共享会话库找到用户实例的owner/permit。
- 文件转发原AgentOS文件路由，以认证actor_id选择用户；查询参数／头不能冒用其他用户。
- 当前不支持跨实例分享：前端禁用入口，HTTP返回501/NOT_SUPPORTED，WebSocket返回NOT_SUPPORTED。
- 原共享组织模式继续使用原组织权限、响应guard和分享，不因实例模式移除其代码。
