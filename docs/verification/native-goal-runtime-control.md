# Native Goal original Runtime control

2026-10-05. This slice connects an active managed Native Goal command to the existing Runtime producer and original cached facade. The Coordinator selects exactly one original managed owner, creates an explicitly parented GOAL_CONTROL handle, and retains the command's full independent authenticated principal. It does not replace the original Turn credential or create another output consumer.

The host capability captures the original Native harness, Binding, Pending, HostRequest, lifecycle, GoalManager and core selector before invoking the temporary command checker. Runtime fixes the request fields, owner revision, project decision, facade and child references; checks repeat after awaits. Changed credentials, parameters or owners cannot retarget a queued command. The existing unary/stream UI payloads and overwrite confirmation remain in use. The initial set path now passes its actual SendInputRequest to the original Native admission.

Execution and result acknowledgement are distinct. Only core's successful original clear drain can select the acknowledgement checker, which verifies the temporary controller and retained original host receipt even if the original Pending has legitimately ended. Pause, resume, set, an unconfirmed exit, and queued clear without an original attempt cannot use this exception. A GoalOperationError before mutation keeps its original confirmation/error UI after original live-target revalidation.
